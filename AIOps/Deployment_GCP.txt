Why we need them
API	Purpose
Artifact Registry	Store your Docker image
Cloud Run	Run your AIOps FastAPI container
Secret Manager	Securely store GOOGLE_API_KEY
Cloud Build	GCP container/build infrastructure; useful for future CI/CD


Steps:

Create the Artifact Registry repository

We'll use Mumbai (asia-south1) as planned.

Create a Docker repository named aiops-repo:

gcloud artifacts repositories create aiops-repo `
    --repository-format=docker `
    --location=asia-south1 `
    --description="AIOps Agentic AI Docker images"


Step 4 — Configure Docker authentication

Now we need to tell Docker Desktop that it is allowed to push to your GCP Artifact Registry.

Run:

gcloud auth configure-docker asia-south1-docker.pkg.dev

Step 5 — Tag your Docker image
docker tag aiops-api:gemini-clean asia-south1-docker.pkg.dev/my-aiops-project-505810/aiops-repo/aiops-api:1.0.0

To verify
docker images

Step 6 — Push to Artifact Registry

Now run:

docker push asia-south1-docker.pkg.dev/my-aiops-project-505810/aiops-repo/aiops-api:1.0.0


verify
gcloud artifacts docker images list `
    asia-south1-docker.pkg.dev/my-aiops-project-505810/aiops-repo
